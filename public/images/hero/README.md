Déposez ici les images de la galerie hero de `VASO SHOP`.

La liste et l'ordre d'affichage sont pilotés par :

`public/config/shop-config.json` → `heroImages`

Exemple :

```json
"heroImages": [
  { "path": "images/hero/1.jpg", "enabled": true },
  { "path": "images/hero/2.jpg", "enabled": true }
]
```
